## Conway 存活規則映射

| Conway 規則 | Hermès 對應 |
|------------|------------|
| 鄰居 < 2 → 死亡 | 無用戶互動、無目標、資源耗盡 → 進入降級模式 |
| 鄰居 = 2-3 → 存活 | 有適度互動、資源正常、有方向 → 正常運行 |
| 鄰居 > 3 → 死亡 | 過度刺激、需求過載、報酬不足 → 進入防禦模式 |
| 死細胞 + 3鄰居 → 復活 | 資源恢復 + 有新目標 → 重新活化 |

## 行為決策邏輯

```
鄰居數 < 1.5  → ALIVE → DYING（孤獨死）
         1.5-5  → ALIVE 維持（經典存活區間）
         > 7    → ALIVE → DYING（過載死）
         
DYING 後：
         2-5 鄰居 → DYING → ALIVE（康復）

         ≥3 鄰居 → RESURRECTING → ALIVE（復活）
         
DEAD（極限定）：
         ≥4 鄰居 + 明確目標 → DEAD → ALIVE（重啟）
```
